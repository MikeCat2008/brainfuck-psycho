# BrainFuck Psycho
<!-- MikeCat & CommandoMagia made this :3 -->
BrainFuck es insanamente retorcido... Así que, ¡quién mejor que un **`psycho`** para interpretar tu demente código! :D

---

**BrainFuck Psycho** (`psycho`) es un proyecto libre y de código abierto escrito en `C` (*¿por qué no?* jejeje) por 2 completos degenerados que no tienen nada mejor que hacer que escribir otro intérprete más para el lenguaje esotérico BrainFuck.

La intención principal de este proyecto es educativa. Queremos poner en práctica nuestros conocimientos sobre el lenguaje `C` y utilizar `git` en un entorno colaborativo (y con mucho humor xD), aprovechando que el minimalismo y simplicidad de BrainFuck ofrece un reto bastante asequible y no por ello menos interesante, a la hora de crear un intérprete para este lenguaje.
